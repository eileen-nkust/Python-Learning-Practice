# 🐍 Python 基礎與物件導向程式設計自主學習紀錄

本專案紀錄自學 Python 過程中的核心語法練習，內容涵蓋資料結構、流程控制、模組化工具開發至物件導向設計（OOP），為後續金資所之金融數據分析與 AI 理財模型建置奠定底層基礎。

---

## 📌 學習章節與實作主題

### 1. 資料型態與基礎邏輯
* **變數與基本型態：** 字串（String）、數字（Number）、布林值（Boolean）與命名規範。
* **字串與數學處理：** 內建函式（`lower()`, `replace()`, `index()`）與 `math` 模組應用（`floor()`, `ceil()`, `sqrt()`）。
* **資料結構：**
  * `List` 列表：元素操作（`append()`, `insert()`, `pop()`, `sort()`, 切片 `[0:2]`）。
  * `Tuple` 元組：不可變性（Immutability）理解與長度計算。
  * `Dictionary` 字典：Key-Value 鍵值對應用。

### 2. 流程控制與互動邏輯
* **邏輯判斷：** `if-elif-else` 搭配邏輯運算子（`and`, `or`, `not`）。
* **迴圈結構：** `while` 迴圈實作（猜數字遊戲、嘗試次數限制）與 `for` 迴圈（`range()`, 巢狀迴圈解析二維列表）。
* **函式開發：** 參數傳遞、`return` 回傳值，以及多條件最大值判斷（`max_num`）。

### 3. 檔案處理與套件模組
* **檔案讀寫 (I/O)：** 相對與絕對路徑、以 `utf-8` 編碼處理中文檔案、使用 `with open()` 自動關閉檔案機制。
* **模組化開發：** 自訂 `tool.py` 模組匯入、`sys.path` 環境查詢與第三方套件 `numpy` 載入。

### 4. 物件導向程式設計 (OOP)
* **類別與物件：** 運用 `class` 建立 `Phone` 模型，寫入建構子 `__init__` 與自訂物件函式。
* **模組繼承 (Inheritance)：** 實作跨檔案 `Student` 類別繼承，體現程式碼重用性（Reusability）。
* **綜合小專案：** 結合類別與列表開發文字版【基礎問答系統】。
